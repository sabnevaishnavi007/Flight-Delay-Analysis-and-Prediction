# ✈️ Flight Delay Analysis and Prediction

## Overview

This project analyzes historical flight data to identify the major factors responsible for flight delays and predicts whether a flight will be delayed or not using Machine Learning.

The project combines SQL, Python, Power BI, and Machine Learning to transform raw flight data into meaningful business insights.

---

## Objectives

- Analyze flight delay patterns.
- Identify the major causes of delays.
- Build predictive machine learning models.
- Visualize delay trends using Power BI.

---

## Dataset

The dataset is taken from the Kaggle - https://www.kaggle.com/datasets/robikscube/flight-delay-dataset-20182022

The dataset contains historical flight information including:
- Airline
- Origin Airport
- Destination Airport
- Departure Time
- Arrival Time
- Delay Time
- Distance
